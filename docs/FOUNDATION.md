# Ramptium — Foundation 0.1

## Product authority
Ramptium is a technology company developing investment intelligence, portfolio analytics, risk visibility, and human-governed institutional workflows. It is **not** represented as a licensed broker, custodian, or investment adviser.

## Phase boundaries
Phase 0.1: public corporate site, design direction, transparent positioning and technical foundation only.
Out of scope: investor onboarding, live trading, money movement, custody, regulated advice, fabricated market data, AI recommendations, production deployment.

## Proposed product modules (not implemented)
- Portfolio OS
- Investment Intelligence
- Risk Intelligence
- Wealth Workspaces
- Institutional Workflow & Audit

## Architecture direction
Modular TypeScript application with future PostgreSQL backend, isolated tenant authorization, verified financial data provenance, immutable decision audit history, and regulated partner integrations where required. These are design targets, not implemented features.

## Verification
Run npm install, npm run build, npm run dev. Check desktop/mobile navigation, contrast, keyboard focus, reduced motion and contact CTA. Do not call this production-certified until the exact deployed build has been inspected.

## Next gate
Verify repository CI and rendered preview, then separately approve product discovery and regulatory feasibility. No next-phase implementation without approval.
